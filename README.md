# CodeAlpha Hangman Game

## Project Description

This is a simple text-based Hangman game developed using Python as part of the CodeAlpha Python Programming Internship.

The player has to guess a hidden word one letter at a time.

## Features

- Uses 5 predefined words
- Randomly selects a word
- Maximum 6 wrong guesses
- Console-based game
- Shows win or game-over message

## Technologies Used

- Python
- Random module
- Lists
- Strings
- Loops
- If-else conditions

## How to Run

1. Install Python.
2. Open `hangman.py`.
3. Run the Python file.
4. Enter one letter at a time.
